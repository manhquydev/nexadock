Hồ sơ Zalo

Mỗi hồ sơ chạy trong hộp cát tách biệt, không chạm vào dữ liệu Zalo chính.

Chưa có hồ sơ nào

Tạo hồ sơ mới để đăng nhập tài khoản Zalo tách biệt.

    Sao lưu ngoại tuyến

    Sao lưu yêu cầu hồ sơ đang dừng và kiểm tra mã băm SHA-256.

    Lưu ý khôi phục an toàn: Thao tác khôi phục luôn tạo một hồ sơ MỚI, không bao giờ ghi đè lên hồ sơ gốc hoặc dữ liệu Zalo chính.

    Chưa có bản sao lưu nào

    Bạn có thể tạo bản sao lưu từ menu thao tác của một hồ sơ đang dừng.

    Bản sao lưu Hồ sơ nguồn Tệp / Dung lượng Thời điểm tạo Xác minh Thao tác
