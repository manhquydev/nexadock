Isolation & Security Guarantees

  • Non-privileged execution: Runs strictly as standard user (asInvoker), zero drivers or HKLM writes.
  • Primary Zalo protection: Inspects %APPDATA%\ZaloData\lockfile via Restart Manager and blocks any stop/kill targeting primary PIDs.
  • Duplicate account guard: Blocks launching two profiles with the same logged-in zalo_user_id simultaneously.
  • Offline atomic backups: Staged via .partial with SHA-256 backup.json; restores strictly into a new profile.
  • Known OS limits: Concurrent voice/video calls remain blocked by global named pipe PipeZCallRecv; notifications share AUMID com.vng.zalo.
