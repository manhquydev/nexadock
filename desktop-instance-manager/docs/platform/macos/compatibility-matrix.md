## 1. Mandatory 6-State Verification Taxonomy

Every subsystem and claim across `docs/platform/macos/**` and `plans/reports/macos/**` uses **only** these 6 verification states:

| State | Exact Meaning in This Worktree |
| :--- | :--- |
| **`STATIC_VERIFIED`** | Proven by Darwin/XNU headers (`<sys/un.h>`, `<sys/syslimits.h>`, `<mach-o/loader.h>`, `<mach-o/fat.h>`), Chromium/Electron source, reverse-engineered VNG `app.asar` inspection, and zero-warning `cargo check` + `cargo clippy -- -D warnings` across `aarch64-apple-darwin` & `x86_64-apple-darwin`. |
| **`WINDOWS_HOST_FIXTURE_TESTED`** | Executed and passing on the local Windows x64 host via `MockMacOsSystemOps`, `HostFixtureMacOsOps`, `dim_macos_cli`, and `fixture-macos-app.mjs`. |
| **`DARWIN_NATIVE_TESTED`** | Executed natively on an Apple macOS kernel (`macos-15` `arm64` or `macos-15-intel` `x86_64`). **Never claimed in this local Windows run (`0` claims).** |
| **`LIVE_ZALO_TESTED`** | Executed on physical Apple hardware against signed official VNG `/Applications/Zalo.app` with user-driven QR sessions. **Never claimed in this run (`0` claims).** |
| **`BLOCKED`** | Prevented by an explicit upstream architectural constraint or environment/authorization gate. |
| **`NOT_TESTED`** | Requires native Darwin kernel execution or live `Zalo.app` GUI hardware verification not yet run. |
