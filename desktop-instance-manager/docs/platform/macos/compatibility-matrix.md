# macOS Multi-Instance Compatibility Matrix (`VERIFIED` Contracts vs `HYPOTHESES`)

**Last Updated:** `2026-11-17`

**Targets Verified by Compiler & Clippy:** `aarch64-apple-darwin` (Apple Silicon), `x86_64-apple-darwin` (Intel), `x86_64-pc-windows-gnu` (Host)

---

## 1. Epistemic Classification Rules

Every technical statement in this matrix is classified into one of two strict categories:
- **`VERIFIED`:** Grounded in Darwin/XNU kernel headers (`<sys/un.h>`, `<sys/syslimits.h>`, `<mach-o/loader.h>`, `<mach-o/fat.h>`), Chromium `process_singleton_posix.cc` / Electron source contracts, static inspection of official Zalo `app.asar`, compiler/clippy verification on `aarch64-apple-darwin` & `x86_64-apple-darwin`, and passing automated Rust + Node fixture suites.
- **`HYPOTHESIS` (Requires Physical Mac Test):** Behavior of current/future official VNG `/Applications/Zalo.app` binaries on live macOS Sonoma/Sequoia/Tahoe GUI sessions that cannot be claimed as `SUPPORTED_AND_TESTED` without physical Mac execution.
