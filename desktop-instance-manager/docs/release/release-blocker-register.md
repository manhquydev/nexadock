## 3. Permanent Architectural & Vendor Boundaries (`BLOCKED` Non-Defects — Disclose Honestly)

1. **Windows Concurrent Voice/Video Calls (`F-WIN-06`):** Official `ZaloCall.exe` binds global named pipes `\\.\pipe\PipeZCallRecv` and `\\.\pipe\PipeZCallSend`; simultaneous calls across two Windows accounts are architecturally `BLOCKED` without forbidden binary/ASAR patching.
2. **Windows Action Center Toast Grouping & `zalo://` Deep Links (`F-WIN-05`, `F-WIN-01`):** Official `Zalo.exe` hardcodes `AppUserModelId("com.vng.zalo")` and writes per-user `HKCU\Software\Classes\zalo`; users are guided to enable Zalo's in-app `notiWin` banner (`PARTIALLY_SUPPORTED`).
3. **macOS Shared `CFBundleIdentifier` & `/tmp/socketzalo*2021` (`F-MAC-04`, `F-MAC-05`):** Re-signing `Zalo.app` breaks `SecureCipher.checkAppSigned()`; Notification Center groups banners under `com.vng.zalo` (Dock badges remain per-instance) and `ZaloCall` sockets support sequential call handoff only.
4. **Official VNG Zalo Desktop on Linux (`F-UBU-01`):** VNG distributes no official Linux client (`UNSUPPORTED`); Ubuntu support is strictly limited to synthetic fixtures and user-supplied local `.AppImage` binaries (`EXPERIMENTAL`), with zero VNG binaries redistributed.
